# MinecraftCapes Mod
This respository contains the actual mod for MinecraftCapes. The mod itself is simple. It downloads textures from https://api.minecraftcapes.net/profile/{uuid} and then applies them in game.

1.16.1+ is using the [MultiLoader-Template](https://github.com/jaredlll08/MultiLoader-Template) to simplify Forge, Fabric and NeoForge builds.
